# 0033: Frame allocation and interaction ownership

Content allocation and separation between independently painted children must belong to the same frame model. This prevents local renderer spacing from contradicting the content area, and makes choice geometry depend on the final face that is actually rendered.

A layer's typed dismissal policy is the authority for outside and Escape observations. Persistent details retain their existing trigger; narrow presentation moves that same node into the active header so it remains reachable without inventing another close action.

Directory browsing is a host observation owned by Services and correlated with its draft owner and request ticket. Selecting an observed path updates the same draft through the existing internal bridge; it does not submit a command. Focus transfers from a loading root to the ready input only while the user still owns that root focus, preserving deliberate focus changes.

Outside dismissal also carries a typed handled result: physical pointer focus happens after capture, so the host cancels that default only when the modeled active layer was actually closed. Otherwise a correctly applied restoration could immediately be overwritten.

Facts own their positive internal layout, with label above value, while the collection owns separation between facts. This keeps spacing attached to the content without changing field identity, order or values.
