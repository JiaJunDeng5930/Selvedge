# 0035: One prepared scene and local proof evidence

The semantic tree and its independently stored appearance tree could disagree after
pending-request masking. Positional rendering also permitted an unmatched tail to
disappear. A prepared node now carries its own semantics and presentation, so these
relationships no longer depend on two containers being kept in sync.

Bend requires helper definitions to be filled before they are called. A bottom-up
lowering pass therefore carries each child source together with its computed
document. This is a compiler result with retained provenance, rather than another
stored UI model or a second traversal of the same subtree.

Single-use proof declarations and proposition aliases created additional places to
maintain the same guarantee. Their witnesses now live in the owning requirement
fields when Bend permits it. Recursive proofs and proofs requiring named parameter
matching remain named; their complete propositions and production coverage remain.

The semantic scene previously omitted selectable values, activity disclosure data and timeline ownership. The renderer recovered these by searching the raw scene after constructing the document. A field-name search across editors could bind a selector to another editor’s values, and the same activity and conversation were interpreted twice.

These values now travel in the owning semantic node before platform preparation. Finite choices are projected only from the owning editor’s input groups; open input remains open. The renderer constructs the final document from that complete node and uses one canonical choice-data projection. Full source provenance remains available for erasure and geometry laws, without becoming a second rendering authority.

The browser no longer consumes the transplanted desktop component, scroll or scoped stylesheet artifacts. Keeping their generation and certificates created a separate maintenance path without production behavior. Those artifacts and their generation inputs are removed; the consumed theme tokens retain their exact source ranges, hashes and reproducibility.
