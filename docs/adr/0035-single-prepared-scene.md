# 0035: One prepared scene and local proof evidence

The semantic tree and its independently stored appearance tree could disagree after
pending-request masking. Positional rendering also permitted an unmatched tail to
disappear. A prepared node now carries its own semantics and presentation, so these
relationships no longer depend on two containers being kept in sync.

Bend requires helper definitions to be filled before they are called. A bottom-up
lowering pass therefore carries each child source together with its computed
document. This is a compiler result with retained provenance, rather than another
stored UI model or a second traversal of the same subtree.

Single-use proof declarations and proposition aliases created additional places to
maintain the same guarantee. Their witnesses now live in the owning requirement
fields when Bend permits it. Recursive proofs and proofs requiring named parameter
matching remain named; their complete propositions and production coverage remain.
