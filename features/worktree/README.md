# Task workspace resources

`MODEL.bend` owns task-associated workspace resources, their backend identity and
external operation vocabulary. `Local` prepares a Git worktree; `TencentCvm`
prepares a cloud environment. The existing worktree command and query names
remain the public registry vocabulary. `create_workspace_task` selects a backend
and can associate the task with a Work.

`CONTRACT.bend` and `PROOF.bend` bind registry replacement and pending
classification to those production operations. `CODEC.bend` owns public command
declarations, strict completion admission and observable resource records. The
harness feature assembly connects these values to task creation and archiving;
the host interprets committed preparation and cleanup effects.
