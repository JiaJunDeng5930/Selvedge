# Speech interaction

`MODEL.bend` owns the temporary microphone resource, selected ChatGPT audio
connection, correlated dictation results and voice controls. `PROOF.bend` binds
resource cancellation and stale completion requirements to the production step.

Audio effects carry no credentials. The browser interprets recording, WebRTC and
local HTTP effects; the host commits final transcripts and work delegations.
Draft insertion is owned by `interaction/STATE.bend`, which checks the captured
editor revision before applying the result. Conflicting transcripts remain
available for an explicit append.

When no audio-authorized connection exists, `Authorize` emits `BeginAudioLogin`
only while Activity is Idle. The physical adapter opens the popup synchronously,
starts the local official-Codex authorization and navigates using the account
authority's validated URL. Trusted account changes refresh capabilities; merely
observing capabilities never starts authorization. Model-provider sign-in is
independent of this audio grant.
